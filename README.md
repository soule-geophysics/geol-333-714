# GEOL 333 / 714: Geophysical Exploration Methods, Student Materials

Student-facing Google Colab notebooks and datasets for GEOL 333 (undergraduate) and GEOL 714 (graduate), Geophysical Exploration Methods, Queens College, CUNY. Instructor: Dax Soule.

## For students

Homework opens directly in Google Colab. For each assignment:

1. Click the **Open in Colab** link (on the Brightspace assignment page, or the badge in the notebook).
2. In Colab, choose **File > Save a copy in Drive** and work in your own copy.
3. Datasets load automatically from this repository; an upload fallback is provided in each notebook.
4. When finished, download your copy, rename it `HW#_LASTNAME.ipynb`, and submit it to the matching **Brightspace** assignment. Submissions are not accepted here on GitHub.

## What lives here

- `notebooks/` — homework and in-class Colab notebooks (no answer keys).
- `data/` — datasets the notebooks load (synthetic or openly licensed; each carries a provenance note).

This repository is a public, read-only content shelf. **No rosters, names, IDs, grades, or student submissions are ever committed here.** All student work and all grading happen in Brightspace, the institutional system.
