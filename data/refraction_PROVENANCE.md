# `refraction.csv`: Provenance

## Source
**Synthetic.** This dataset is generated, not measured. It supports HW5a. It carries no external license constraint and is fully reproducible from the script, exactly like `pendulum_sample.csv`.

## License
Instructor-created course data, released under CC BY 4.0 with the rest of this repository.

## Generator

Generated by `generate_refraction_data.py` in the course build repository, not published here.

The generator prints a write line for each file it writes and a self-recovery check (recovers v1, v2, crossover, and depth from the picked travel times and compares them to the true inputs).

## Seed
`SEED = 333` (the project convention, matching `generate_pendulum_data.py`). The CSV is bit-for-bit reproducible from this seed.

`generate_pendulum_data.py` is in the course build repository, not published here.

## Columns
| name | unit | description |
|---|---|---|
| `offset_m` | m | geophone offset from the source (3 to 72 m, 3 m spacing) |
| `first_break_ms` | ms | picked first-arrival time, milliseconds (= 1000 × `travel_time_s`) |
| `travel_time_s` | s | the same first-arrival time in seconds; the SI column HW5 fits |

`first_break_ms` and `travel_time_s` carry the same measurement in two units. HW5 fits `travel_time_s` (so the slope comes out in s/m and `1/slope` is directly m/s); `first_break_ms` is provided because field seismographs report first breaks in milliseconds.

24 rows, one forward spread. The same script also writes `refraction_three_layer.csv` (HW5b), with its own provenance file, and a one-reflector file that no published assignment uses. Generating them did not change this file. The course covers flat layers and single spreads only, so no reversed file is made.
