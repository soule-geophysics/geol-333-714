# `refraction_three_layer.csv`: Provenance

## Source
**Synthetic.** This dataset is generated, not measured. It supports the three-layer half of HW5b (Burger §3.3 and §3.4). It carries no external license constraint and is fully reproducible from the script.

## License
Instructor-created course data, released under CC BY 4.0 with the rest of this repository.

## Generator

Generated by `generate_refraction_data.py` (`build_three_layer`) in the course build repository, not published here.

The generator prints a self-recovery check for each file.

## Seed
`SEED = 333` (the project convention). `numpy.random.default_rng(333)` draws one noise value per geophone in offset order. The CSV is bit-for-bit reproducible from this seed. The seed was not changed after looking at the draw. The recovery table is kept in the course build repository's copy of this file.

## Columns
| name | unit | description |
|---|---|---|
| `offset_m` | m | geophone offset from the source (2 to 96 m, 2 m spacing) |
| `first_break_ms` | ms | picked first-arrival time, milliseconds |
| `travel_time_s` | s | the same time in seconds; the column HW5 fits |

48 rows, one forward spread.
